# StudentAge Mod 管理器

这是游戏《学生时代》的 BepInEx 与 Steam 创意工坊 DLL Mod 管理器。

<p align="center">
  <img src="Assets/ModManagerIcon.png" width="160" alt="StudentAge Mod 管理器" />
</p>

它可以：

- 从 EXE 内嵌包一键离线安装 BepInEx 和工坊桥接组件（Workshop Bridge）；
- 打开推荐 Mod 的 Steam 工坊页面；
- 列出当前 Steam 账号订阅的 DLL 工坊项目，包括未收录、私密和已禁用的；
- 启用或禁用工坊 DLL，不取消订阅、不动 Steam 源文件；
- 识别手动放入 `BepInEx/plugins` 的本地 DLL，启用或禁用时不删除文件；
- 本地版与工坊版 `BepInPlugin` GUID 相同时给出冲突警告。

> 推荐目录只是官方整理的推荐列表，不是加载白名单。没进推荐目录的工坊 Mod 同样可以正常加载和运行。

## 📥 下载

**[下载 ModManager.exe](https://github.com/white12666/StudentAgeModManager/releases/latest/download/ModManager.exe)**

- 支持 Windows 10 / Windows 11；
- 下载后直接运行，不需要安装；
- BepInEx 与桥接组件已内嵌在 EXE 中，安装前置全程不联网；
- 放在任意位置都行，管理器会自动寻找游戏目录；直接从 Steam 工坊目录运行时会先复制到本机临时运行目录，避免占用工坊文件而让 Steam 一直显示游戏运行中。

## 🚀 三步开始使用

### 1. 安装前置

1. 完全退出游戏；
2. 运行 `ModManager.exe`；
3. 点击顶部黄色提示中的“**一键安装完整前置**”；
4. 安装完成后点击“**刷新**”，或启动一次游戏。

解压和安装全部离线完成，具体位置与校验方式见 [DEVELOPMENT.md](DEVELOPMENT.md)。

已经装过 BepInEx 的话，按钮会变成“**安装工坊 Mod 支持**”，只补装或更新桥接组件。

工坊内容始终由 Steam 下载；推荐目录在后台获取，拿不到也不影响本地订阅的识别和启停。

### 2. 安装工坊 DLL Mod

可以从管理器的推荐目录打开工坊页面，也可以直接用作者给的 Steam 链接。

```text
点击“打开工坊页面”
        ↓
在 Steam 中点击订阅
        ↓
等待下载完成
        ↓
游戏关闭时点“刷新”，或下次启动游戏时自动启用
```

Steam 正在运行时会直接跳到客户端内的项目页，否则打开网页。订阅和取消订阅都在 Steam 中完成。

装好桥接组件之后的新订阅，下载完成后点“刷新”或下次启动游戏就会自动启用。安装前就订阅的项目
不会被自动全部打开，它们会列在管理器里，手动点“启用”即可。

### 3. 管理 Mod

- 工坊 Mod：在 Steam 中订阅/取消；在管理器卡片或游戏“本地”页开启/关闭；
- 手动 DLL：在管理器中点“启用”或“禁用”；
- 只能在游戏关闭时切换，改完立即同步，下次启动生效；
- 禁用工坊项目不会取消订阅。Steam 照常下载作者更新，项目保持禁用；重新启用时直接用最新版。

## 🖥️ 界面状态是什么意思

状态由来源、是否收录和当前启用情况组成。

| 界面状态 | 含义 |
|---|---|
| `Steam 工坊 · 已收录 · 已启用` | 已收录且本机已启用，合并为一张卡片 |
| `Steam 工坊 · 已收录 · 未启用` | 已收录但本机没有加载（未订阅，或已关闭） |
| `Steam 工坊 · 未收录 · 已启用` | 没收录但已启用，可正常运行 |
| `Steam 工坊 · … · 下载中` | Steam 还没下载完或正在更新，暂不加载 |
| `Steam 工坊 · … · 待刷新` | 已在游戏中启用，点“刷新”或启动一次游戏即可加载 |
| `Steam 工坊 · … · 缺少描述文件 / 文件不完整` | 不符合 `workshop-plugin.json` 包规范，不会加载 |
| `Steam 工坊 · … · 重复 GUID` | 与另一个待加载 Mod 的 GUID 相同，只能留一个 |
| `本地 · 未收录 · 已启用` | 手动安装的 DLL，当前在插件目录中 |
| `本地 · 未收录 · 未启用` | 已被管理器移出插件目录 |
| `本地 · 未收录 · 路径冲突` | 启用区和禁用区同时有同名项目，需要手动处理 |
| `本地 · 未收录 · 重复 GUID` | 与另一个 Mod 的 GUID 相同，通常是装重复了 |

### “收录”和“启用”不是一回事

- **收录**：是否进入官方推荐列表；
- **启用**：Mod 是否已经成功桥接，能被游戏加载。

所以“未收录 · 已启用”完全正常。

## 🔌 本地 DLL 怎么显示

管理器会扫描：

```text
BepInEx/plugins
BepInEx/ModManager/disabled
```

只要 DLL 中有有效的 `BepInPlugin` 声明，就会显示名称、版本和路径。

推荐每个 Mod 使用独立目录：

```text
BepInEx/plugins/MyMod/
├─ MyMod.dll
└─ Dependency.dll
```

点击“禁用”时，整个目录会移动到：

```text
BepInEx/ModManager/disabled/MyMod
```

重新启用时原样移回。管理器没有删除按钮，也不会自动删你的 DLL。

## 🔍 它是怎么让工坊 DLL 生效的

游戏原生 Mod 系统只记录你启用了哪些工坊项目，不会加载 DLL。桥接组件在插件加载之前运行，
把已订阅并已启用的工坊目录接进 BepInEx 的插件目录，因此同一次启动就能生效。

订阅情况、下载状态或包格式只要有一项不明确，它就本次不加载，而不是猜测。

推荐目录来自仓库中的 `mods.json`；索引没写名称和简介时，管理器会从 Steam 读取并缓存。

完整规则与实现细节见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## ❓ 常见问题

### 未收录的工坊 Mod 能运行吗？

可以。只要已订阅、下载完成、已启用，且包格式正确就行。

管理器直接读取本地 Steam 订阅数据，所以未收录甚至私密的项目也能显示和管理。

### 已收录的工坊 Mod 为什么显示“未启用”？

能读到 Steam 状态时，管理器会进一步显示“下载中”“待刷新”“缺少描述文件”或“文件不完整”。
显示“未启用”的常见原因：

- 还没在 Steam 订阅；
- Steam 没下载完，或正在更新；
- 是安装前就有的订阅，还没手动开启；
- 你自己关掉了；
- 工坊包没有有效声明；
- 还没启动过游戏，也没点过“刷新”。

### 为什么同一个已收录工坊 Mod 没有显示两次？

管理器按 Workshop ID 把推荐目录信息和本机安装状态合并成一张卡片。未收录但有效的订阅同样
列在“Steam 创意工坊目录”里。

### 管理器显示已启用，为什么游戏“本地”页却全部显示关闭？

这是旧版工坊桥接组件触发的原版存档路径初始化问题：DLL 可以由 BepInEx 正常加载，但游戏界面可能从 `Saves/user/_mod` 读取状态，而管理器写入的是当前 Steam 用户目录。完全退出游戏，在管理器顶部点击“安装工坊 Mod 支持”更新桥接组件后重启；现有开关状态不需要重设。

### 在管理器或游戏“本地”页关闭后还会自动开启吗？

不会，桥接组件尊重手动关闭。禁用只是把它从启用列表中移除，不取消订阅、不动源文件。
取消后重新订阅同一个 Workshop ID，也不会自动开启。

### 本地版和工坊版都有，而且 GUID 相同怎么办？

不要同时启用——BepInEx 会把它们当成同一个插件，最终加载哪个取决于扫描顺序。
禁用其中任意一个，刷新后警告就会消失。

### 普通 JSON Mod 会被当成 DLL 加载吗？

不会。没有有效 DLL 声明的普通工坊项目继续由游戏原生 Mod 系统管理。

### 点击按钮后为什么没有自动订阅？

按钮是“打开工坊页面”，不是“订阅”。请在打开的页面里自己点订阅。

### 顶部显示“工坊 Mod 支持缺失或需更新”怎么办？

完全退出游戏，然后点击“安装工坊 Mod 支持”。管理器会用内嵌版本修复。

### 如何查看加载结果？

检查：

```text
BepInEx/WorkshopBridge.log
BepInEx/ModManager/WorkshopRefresh.log
BepInEx/LogOutput.log
```

### 取消订阅后会留下 DLL 吗？

不会。Steam 负责删除内容，桥接组件在下次启动时清理对应的加载项。

### 杀毒软件为什么可能提示？

管理器要写入 BepInEx 目录，桥接组件要创建目录链接，少数安全软件会因此报警。
建议只从本仓库 Release 下载并核对来源。

## 🔐 使用 DLL Mod 前请注意

DLL Mod 是可执行代码，权限与游戏进程相同。请只安装可信作者发布的项目，并优先查看源码和社区反馈。

管理器和桥接组件只检查订阅、下载状态、manifest 和路径，无法替你判断一个 Mod 的功能是否可信。
